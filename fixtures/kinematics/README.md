# 刚体运动学固定参考

参考生成独立运行。
产品命令不生成参考。
产品测试只读取JSON。
它们不运行CPU运动学。
它们不启动Python。

## 预先固定容限

比较采用如下公式：
`abs(actual-reference) <= 2e-5 + 2e-5*abs(reference)`。

容限覆盖f32舍入积累。
参考保留原生double结果。
输入状态先转换为f32。
样本种子固定为1789。
每个模型包含八组状态。
状态包含非单位四元数。
状态包含负单位四元数。
旋转覆盖偏心关节。
原生参考不证明完整等价。
