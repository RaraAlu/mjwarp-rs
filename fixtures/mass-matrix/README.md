# 质量矩阵固定参考

产品测试只读取静态JSON。
测试不生成参考或编译模型。
测试不启动Python。

## 固定容限

容限在首次GPU执行前固定：
`abs(actual-reference) <= 2e-5 + 2e-5*abs(reference)`。

种子固定为1789。
六个模型各含八组状态。
参考先把状态量化至f32。
原生输出保留double精度。

## 独立制备

`reference.cpp`独立运行。
它调用原生刚体运动学。
它继续调用`mj_comPos`。
它调用`mj_crb`生成复合惯量。
它用`mj_fullM`展开稠密矩阵。
它不调用Rust候选公式。
原生版本为3.12.0。
原生许可为Apache-2.0。
生成器拒绝肌腱与执行器模型。
该检查不代表完整Model准入。

原生候选提交如下：
`13827e9ee56f097f57acf69ae52b078f9839682d`。

冻结Warp提交如下：
`71da24d956378a87a703b6e1442b13aec0c4ac29`。

## 解析证据

新增armature链含三个自由度。
默认矩阵如下：

```text
6.25   1.75     0
1.75   1.6875   0
0      0        4.75
```

速度`[1,2,3]`对应动能31.375。
测试另核对零惯量半正定输入。
零惯量模型只保留armature对角线。
该模型不提供原生可编译证据。
探针不承诺正定或可逆。

## 完整性

manifest登记全部固定输入。
它覆盖六组JSON与六个MJB。
它覆盖生成器与新增XML。
脚本先核对全部SHA-256。
再生成命令见验收报告。
