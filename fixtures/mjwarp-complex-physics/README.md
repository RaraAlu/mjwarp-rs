# D04复杂物理参考

本目录保存上游参考。
参考不实现产品物理。

## 冻结身份

- 上游提交为`71da24d`。
- MuJoCo采用`3.15.0`。
- Warp采用`1.15.0`。
- NumPy采用`2.5.4`。
- 最终作者批次为`run-5`。

作者脚本逐文件比对源码。
它比对安装包与冻结树。
它拒绝任何源码差异。

## 作者执行

脚本只供离线制样。
产品测试不会启动它。

```powershell
$env:MJWARP_D04_RUN_ID='run-new'
target/mjwarp-parallel/venv/Scripts/python.exe fixtures/mjwarp-complex-physics/reference.py
```

每个批次独占目录。
脚本先保存输入快照。
脚本逐案例保存结果。
失败批次不会被覆盖。

## 验证边界

静态测试核对全部哈希。
它也核对精度与分母。
它不证明Rust物理等价。
它不证明公平性能。
