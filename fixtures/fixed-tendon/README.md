# 固定肌腱静态参考

此目录关联G01辅助子集。
它不验收完整G01。

- 原生版本：MuJoCo 3.12.0。
- 随机种子：1789。
- 样本数：8。
- 绝对与相对容限：`2e-5`。
- 肌腱数：4。
- 原生CSR元素数：8。
- `nq=14`，`nv=12`。

模型保留free与ball关节。
肌腱只引用hinge与slide。
样本覆盖正负与零系数。
样本打乱关节项顺序。
参考保留非零关节默认值。
长度直接累加原始qpos。
它不减去关节默认值。

作者工具位于`reference.cpp`。
开发人员用C++生成参考。
作者工具只接收三个路径。
它读取XML并输出JSON与MJB。
它先归一化非标量关节。
它将状态舍入至f32。
原生工具随后使用f64计算。
产品测试只读取静态文件。
产品测试不执行作者工具。

`manifest.json`冻结四份文件。
测试逐项检查SHA256。
清单还记录原生DLL哈希。

详见[固定肌腱报告](../../docs/windows-resident-fixed-tendon.md)。
