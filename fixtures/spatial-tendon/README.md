# 空间肌腱静态参考

范围：site与pulley子集。
矩阵功能ID：G01。
本组不证明完整G01。

开发工具采用MuJoCo 3.12.0。
它使用原生f64计算参考。
开发者先规范化旋转。
开发者再将物理输入转为f32。
产品测试只读取静态JSON。
产品测试不调用原生物理。
产品测试不编译XML。
产品链不运行Python。

| 文件 | 用途 |
| --- | --- |
| `mixed-tree.xml` | 开发时编译源模型 |
| `mixed-tree.mjb` | 可信已编译模型 |
| `mixed-tree.json` | 模型字段与八组结果 |
| `reference.cpp` | 开发期参考生成工具 |
| `manifest.json` | 固定摘要与DLL摘要 |

种子固定为1789。
模型含七个体与五个关节。
模型含九个site与五条肌腱。
肌腱采用十九项包裹记录。
稀疏力臂采用四十五个槽位。
样本覆盖四种关节。
样本覆盖同体与共享祖先。
样本覆盖mocap与静态路径。
样本覆盖前置及中段滑轮。
滑轮除数分别为2与4。
后续滑轮覆盖前一个比例。
它不累乘历史滑轮除数。

浮点绝对容限固定为`2e-5`。
浮点相对容限固定为`2e-5`。
整数参考要求逐项精确一致。
包裹数组保留双点容量。
未使用槽位全部保持零。

开发者手工运行C++工具。
工具读取XML并写出MJB与JSON。
产品验收脚本不会调用工具。
清单固定四个文件的SHA-256。
修改样本须重新审查全部摘要。
