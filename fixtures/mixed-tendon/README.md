# 混合肌腱静态参考

范围：G01严格辅助子集。
MuJoCo版本为3.12.0。
清单锁定四份文件哈希。
产品测试只读取固定JSON。
产品测试不生成原生参考。
产品测试不启动Python。

模型复用球柱样本的刚体树。
它交错排列十四条肌腱。
固定肌腱编号为0、3、7、13。
其余十条路径采用空间肌腱。
CSR包含十六个槽位。
模型包含四十三项包裹记录。
包裹结果保留原生双点容量。
零系数固定行保留原生CSR。
固定行共享当前包裹游标。
固定行的包裹数量始终为零。

参考固定十二组输入状态。
`seed=2101`只标识样本组。
工具不调用随机数生成器。
输入状态与尺寸先舍入为f32。
原生物理随后采用f64。
半径周期包含三组独立尺寸。
四轮状态改变有效包裹数量。
绝对与相对容限均为`2e-5`。
整数结果要求精确一致。

开发者单独编译`reference.cpp`。
该工具调用原生XML编译器。
它输出固定MJB与JSON。
它不进入产品构建链。

```text
reference.exe mixed-tree.xml mixed-tree.json mixed-tree.mjb
```

详细证据见[混合报告](../../docs/windows-resident-tendon.md)。
