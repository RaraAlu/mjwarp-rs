# 质心固定参考

产品测试只读取静态JSON。
测试不生成参考或编译模型。
测试不启动Python。

## 预先固定容限

比较公式如下：
`abs(actual-reference) <= 2e-5 + 2e-5*abs(reference)`。

种子固定为1789。
每个模型包含八组状态。
输入状态先转换为f32。
原生参考保留double结果。
GPU实现不得放宽容限。

## 独立证据

`reference.cpp`独立运行。
它调用原生`mj_kinematics`。
它继续调用原生`mj_comPos`。
它不调用Rust物理算法。
它输出四项质心字段。
它另存原生根体索引。
原生版本为3.12.0。
原生许可为Apache-2.0。

原生候选提交如下：
`13827e9ee56f097f57acf69ae52b078f9839682d`。

冻结Warp提交如下：
`71da24d956378a87a703b6e1442b13aec0c4ac29`。

## 零质量差异

冻结Warp保留零加权矩。
因此零质量子树质心为零。
原生CPU采用最小质量阈值。
低于阈值时它选取`xipos`。
`massless-tree.json`保留原值。
测试不得篡改该独立参考。
测试用解析零值检验Warp。
另一项测试检验微小正质量。
它采用手算质心作为证据。
它不声称原生CPU等价。

## 完整性

`manifest.json`登记全部输入。
它覆盖五组JSON与五个MJB。
它覆盖生成器与新增XML。
脚本先核对各项SHA-256。
再生成命令见验收报告。
