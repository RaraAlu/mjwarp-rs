# 质量矩阵求解固定参考

产品测试只读取静态JSON。
测试不生成参考或编译模型。
测试不启动Python。
模型输入复用矩阵参考。
六个模型各含八组状态。
每组状态包含三个右端项。
状态种子固定为1789。
右端项种子固定为9701。
状态与右端项先量化至f32。
原生分解与解保留double精度。

## 固定容限

首次GPU执行前固定以下容限：

```text
abs(actual-reference) <= 2e-4 + 2e-4*abs(reference)
normalized residual <= 2e-5
normalized reconstruction <= 2e-6
```

测试不得放宽这些容限。
矩阵探针仍沿用原定容限。
新容限不覆盖旧矩阵验收。

## 独立制备

生成器只调用原生物理入口。
它执行刚体运动学与质心。
它调用`mj_crb`与`mj_factorM`。
它调用`mj_solveM`求多个右端项。
它直接展开原生稀疏因子。
它不执行候选Rust公式。
它不执行候选CUDA公式。
它拒绝肌腱与执行器模型。
该检查不代表完整模型准入。
原生版本为MuJoCo 3.12.0。
原生许可为Apache-2.0。

原生候选提交如下：


## 范围与完整性

模型覆盖四种关节与多根。
模型保留旋转惯性与armature。
零自由度模型输出空因子。
右端项覆盖零、符号与随机值。
manifest登记十九项固定输入。
它覆盖生成器与六组求解JSON。
它覆盖六组模型JSON与六个MJB。
脚本先核对全部SHA-256。
再生成命令见验收报告。

本参考不证明完整G03等价。
它不证明分块或稀疏布局等价。
它不证明休眠与任意条件数。
