# G03冻结分块参考

本目录仅保存离线参考。
产品构建与测试不运行Python。
`reference.py`只服务参考制作。
它调用冻结上游的原始阶段。
测试读取静态JSON并核对哈希。

本轮保留六模型与全部配置。
测试不直接比较异义因子。
上三角分解采用Cholesky格式。
原生矩阵派生同义f64参考。
原生解仍读取原冻结资料。
产品求解全链保持f32。

原失败摘要保留历史证据。
首差目录为`first-difference/`。
离线追踪工具为`first_difference.py`。
后续专项双模式各8过0败。
单元测试双模式各10过0败。
每模式仍有20块对照放行。
本目录不证明完整G03通过。
