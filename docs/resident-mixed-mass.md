## 路径与精度

源码位于以下位置：

```text
src/physics/mass_solve/sparse/mixed/solve/resident.rs
```

新计划提供以下接口：

```rust
SparseMassMixedResidentPlan
SparseMassMixedResidentData
```

计划持有原质量矩阵计划。
它另持有三路混合求解计划。
调用方只写位置(qpos)。
调用方也可独立写右端项(RHS)。
产品不向宿主回读并重传矩阵。

设备依次执行以下阶段：

1. 刚体运动学与质心。
2. 复合惯量(CRB)与稠密矩阵。
3. 完整源验证与CSR采集。
4. 同代双缓存与混合分解。
5. 完成合并因子消费与求解。

CSR指压缩稀疏行(CSR)。
三路保持原Sparse/Small/Compact。
计划不绕过旧纯Sparse准入。
它直接复用两项常驻计划。
构造先拒绝不支持的Tile。
拓扑检查维数与完整父链。
新入口不接入MathDx二进制。
旧ABI与旧计算内核保持。

| 字段 | 类型与行为 |
| --- | --- |
| qpos与惯性模型字段 | f32 |
| 位置、质心与空间惯量 | f32 |
| CRB、M、中间量与累加 | 原f32路径不改 |
| CSR采集 | f32直接位复制 |
| 三路因子、RHS与解 | 原f32路径不改 |
| 元数据与CSR索引 | i32 |
| 参考、误差与残差 | f64纯诊断，不反馈产品 |
| 编译 | NVRTC12.8，compute70 |
| 选项 | fmad开启，fast_math关闭 |

两个新256线程入口仅验证与复制。
源步长采用`10*nbody+nv²`。
验证覆盖全部CRB与稠密矩阵。
验证也检查前后四槽守卫。
非CSR上三角仍须保持有限。
采集保留目标CSR守卫。
设备冻结同一代双生产者缓存。
读回接口消费完成合并因子。
独立矩阵诊断仍检查当前源。

## 缓存与错误边界

合法qpos写入废弃全部下游。
位置与矩阵刷新也废弃下游。
RHS合法写入仅废弃解。
非法输入拒绝不改变设备状态。
外来计划拒绝不改变已完成缓存。
新采集必须消费新鲜矩阵。
故障必须阻止整批结果发布。
旧CRB故障不决定完成因子寿命。
新采集仍须拒绝同一坏源。
产品不提供CPU物理回退。

本次私有测试实证以下边界：

- 旧非CSR矩阵NaN不破坏缓存解。
- 当前矩阵诊断拒绝该坏源。
- 新采集拒绝完整CRB中的NaN。
- 新采集拒绝未选上三角NaN。
- 源、CSR与status两端守卫均拒绝。
- 修复守卫后各阶段恢复。
- 故障后不发布部分宿主结果。

状态函数还计划覆盖以下边界：

- 世界256位置刷新与阶段失效。
- 未选世界qpos与RHS位型保持。
- RHS更新复用完成因子。
- 全部所有者销毁后快照仍可读。

该函数在中途断言失败。
上述后半段尚无本次通过证据。
我不借旧测试替它放行。

## 独立参考装配

参考组合两个冻结原生模型。
它采用65链与三自由度模型。
组合有68自由度与69个体。
三树大小分别为65、2、1。
CSR长度2149，Small前缀4。
组合属于辅助DTO。
本次没有编译新的原生模型。

助手转录二十一项模型字段。
浮点字段先映射f32。
体、关节、DOF与qpos偏移65。
组合只保留一次世界体惯性。
根CRB采用不同质心框架。
参考不把根CRB求和进世界体。
世界体CRB保持零。

矩阵参考采用冻结原生块直和。
Small三体CRB直接取原生结果。
大树CRB采用独立解析几何。
它使用Z轴旋转与平行轴公式。
它再计算后缀空间惯量。
物理参数先转换f32。
解析累加仅用于f64诊断。

Sparse解复用旧独立LU结果。
Small2解采用二阶闭式逆。
闭式逆读取冻结f32矩阵。
Compact解采用`b/Mdiag`。
参考不读取候选因子或解。
本次不调用旧作者或MuJoCo。
本次不启动Python或SDK探针。

装配首次实际失败1/3。
PowerShell误解析数学数组元素。
它报告`System.Object[] op_Multiply`。
原包装器错误地返回零退出码。
它没有创建预期Tee日志。
报告只归档实际工具错误转录。
报告另保存原脚本与原合同。
转录不冒充原日志文件。

我只补每个数学元素的括号。
第二次装配实际成功2/3。
两态六列残差5.4859754e-17。
参考随后冻结，不运行第三次。
