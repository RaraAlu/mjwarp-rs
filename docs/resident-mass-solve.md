## 计划与接口

本轮沿原[实施计划](implementation-plan.md)。
它复用[常驻CRB](resident-crb.md)设备矩阵。
它不调用旧一次性求解探针。
旧分解与求解算式保持不变。
本轮只拆分设备阶段。
计划创建时完成上传与编译。
更新阶段不重新上传模型。
更新阶段也不重新编译。

| 新接口 | 实际契约 |
| --- | --- |
| `MassSolvePlan::create_data` | 独占CRB、因子、RHS与解；固定RHS数量 |
| `update_position` | 刷新位置前置；废弃因子与解 |
| `update_matrix` | 消费新鲜位置；废弃因子与解 |
| `update_factor` | 读取常驻矩阵；独立保存因子 |
| `update_solve` | 只读缓存因子；不重新分解 |
| `update` | 显式组合四个阶段 |
| `write_rhs` | 检查全量RHS；只废弃解 |
| `write_world_rhs` | 检查后只写指定世界的RHS |
| `write_qpos`与世界入口 | 废弃位置、矩阵、因子与解 |
| `readback` | 检查全部所需守卫与状态；发布独立快照 |

输入拒绝保留已有结果。
跨计划调用拒绝外来状态。
坏主元阻止整批因子发布。
失败世界不会泄露部分成功解。
健康会话允许重新计算恢复。
因子校验与回读采用宿主诊断。
诊断不反馈任何物理数值。
本轮没有CPU产品回退。
