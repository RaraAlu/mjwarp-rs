# 常驻三路混合分解

日期：2026-10-14。
本轮落实常驻CSR混合分解。
它支持稀疏(Sparse)大树。
它也支持小块(Small)前缀。
它还支持紧凑(Compact)块。
它仍拒绝全部Tile块。
七维CUBIN仍缺产品精度准入。
本轮不绕过原PTX门禁。

## 产品接口与范围

新增以下四个公开类型：

```text
SparseMassMixedFactorPlan
SparseMassMixedFactorData
SparseMassMixedFactorOutput
SparseMassMixedFactorWorld
```

入口要求至少一棵Sparse大树。
它不支持纯Small或纯Compact。
它也不提供混合求解入口。
旧Sparse入口仍拒绝非紧凑块。
本轮不放宽旧入口准入。
混合入口检查路由后复用工厂。

调用方只写主CSR矩阵。
物理输入与全部结果采用f32。
元数据采用i32。
本轮没有引入新依赖。
本轮没有执行宿主物理分解。
它仍未接通CRB混合桥接。
输入矩阵仍由调用方提供。

## 同代快照与失效

各缓存保留同会话所有权。
启动复用原同步完成机制。
接口不导出裸设备地址。

`update_gather`捕获主CSR。
它先复制为Sparse输入快照。
随后从该快照复制Small源。
两个因子采用同代输入。
设备复制包含完整源守卫。
GPU验证完整源后才完成采集。

初稿曾让Sparse重读主CSR。
它可能混用两种采集代次。
本轮在GPU测试前修复它。
修复额外占用一份CSR缓冲。
它没有改变冻结物理算子。

`update_factor`复用采集缓存。
旧主M变化不影响缓存因子。
新采集仍检查当前主M。
合法公开写入使所有阶段失效。
非法长度、世界或NaN保持缓存。
外来计划拒绝且保持原缓存。
计算失败禁止整批发布结果。
调用方可以修复输入后重算。
快照独占宿主结果与模型引用。
释放计划不影响既有快照。

## 合并布局与上游顺序

GPU合并三个世界段：

| 段 | 实际含义 |
| --- | --- |
| `prefix` | Small上三角U，下三角正零 |
| `nC` | 全CSR尾，仅Sparse行执行LDL更新 |
| `nv` | 全自由度的对角倒数 |

冻结`factor_m`先执行块分解。
随后它复制全M到CSR尾。
它只对Sparse树登记更新。
最后它对全部nv计算倒数。
Small的CSR尾仍保持原M。
Small倒数采用原M对角。
它不能采用U对角倒数。
Compact倒数也采用原M。

GPU合并仅复制物理位型。
宿主只读取结果与诊断。
产物经过原全PTX门禁。
原fast_math保持关闭。
原fmad保持开启。
原目标仍采用compute_70。
实际NVRTC采用12.8。
本轮不装载任何SDK二进制。

本轮合并三个新调用的预算。
累计3/3，全部用途冻结。
本轮没有重跑旧成功用途。
本轮没有运行旧Small目标。
本轮也没有调用参考作者。
