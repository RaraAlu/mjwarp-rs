## 结论

上游实测返回`[0,0,0,1]`。
本库此前返回`[0,0,0,0]`。
本轮只修改完整入口的零分支。
严格入口及正长度公式不变。
原容差与全部覆盖不变。

生成代码调用四元数重载。
该重载采用`wp::quat_t<wp::float32>`。
它没有改用四维向量重载。
原生头文件与实测结果一致。
注册文档的全零说法不符。

MJWarp按wxyz顺序传入四槽。
Warp依次接收这些槽位。
Warp字段名采用xyzw。
两套命名不改变存储顺序。
所以末位一不是MJWarp单位旋转。
本轮不擅自改成首位一。

## 定向覆盖

新增输入包含四个世界。
它们不替换旧样本或世界。

| 输入 | 路径 |
| --- | --- |
| 正零 | 自由、球、mocap、自由子体 |
| 负零 | 同上 |
| `1e-30`各分量 | 平方和下溢，同上 |
| 单位四元数 | 同上，作为非零对照 |

模型包含五体、两关节。
上游按三条分支调度。
双方采用相同f32输入。
双方比较七项刚体输出。
总计608个标量比较。
比较要求精确数值相等。
正负零在数值上相等。
本轮不声称全输出逐位一致。
两侧同时检查头尾保护槽。

修复前出现129处差异。
修复后608项全部一致。

| `xmat` | 36 | 0 |
| `xipos` | 27 | 0 |

| `xanchor` | 0 | 0 |
