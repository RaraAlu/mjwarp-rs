# 惯性盒流体力

## 范围

本轮落实U038子集。
GPU计算刚体流体力。
GPU再投影广义力。
实现仅含惯性盒分支。
椭球分支会明确拒绝。
共享被动力尚未接入。

源码位于以下文件：

- `src/physics/fluid_force.rs`
- `src/physics/com_velocity.rs`
- `src/physics/resident.rs`
- `src/runtime/transfer/kernel.rs`

## 上游映射

实现跟随冻结上游。
基线提交如下：

```text
71da24d956378a87a703b6e1442b13aec0c4ac29
```

公式来自两个函数：

- `passive.py::_fluid_force`
- `support.py::_apply_ft`

状态全程使用f32。
参数全程使用f32。
CUDA内部使用float。
索引使用i32与int。
实现保留五类周期。
周期分别为独立批次。

实现保留原算序。
三次方仍调用powf。
四次方仍调用powf。
黏性乘法保持左结合。
六维点积从正零累加。
三维点积从首项左结合。
刚体按升序投影。
实现未启用快速数学。
实现保留融合乘加。

## 所有权

计划借用速度计划。
位置与速度必须同源。
质量参数沿用G01。
惯量参数沿用G01。
风速保留独立周期。
密度保留独立周期。
黏度保留独立周期。
失效源会阻止发布。
坏根映射会提前拒绝。
验证不会越界读根。

输出分为两层：

- 刚体力与力矩
- 广义流体力

刚体顺序为力再力矩。
空间速度先角后线。
