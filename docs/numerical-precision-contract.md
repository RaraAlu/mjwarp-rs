## 数值参考优先级

第一参考标准为原生MuJoCo。
它提供共同的误差基准。
先检查既有原生容差。
原生达标即放行该项NP03。
仅原生超差后启用MJWarp。
本库与MJWarp须采用同条件。
两路都计算相对原生的误差。
不再用两路输出距离判定。

当前规则名为`native_error_v2`。
用户于2026-10-11批准5%余量。
它是工程红线，不是物理定理。
本轮保留既有原生容差。
旧值差门禁只保留历史效力。

每个字段块分别计算下式：

```text
t_i = atol_native + rtol_native * abs(native_i)
E_candidate = max_i(abs(candidate_i - native_i) / t_i)
E_mjwarp    = max_i(abs(mjwarp_i    - native_i) / t_i)
redline     = 1.05 * E_mjwarp
```

两路采用相同原生值与分母。
5%作用于最大归一化误差。
它不作用于物理输出值。
它也不放宽原生容差。
等于边界时允许通过。
分母与误差均为零时记零。
分母为零且误差非零时禁行。
非有限误差或红线也禁行。
空字段只能证明形状一致。
零数值样本不能通过汇总。

| 条件 | 固定标注 | NP03放行 |
| --- | --- | --- |
| `E_candidate <= 1` | 原生放行 | 是 |
| 原生超差，`E_candidate <= E_mjwarp` | 对照放行 | 是 |
| `E_mjwarp < E_candidate <= redline` | 红线内放行 | 是 |
| 原生超差，`E_candidate > redline` | 失败不放行 | 否 |
| 缺原生或同条件MJWarp参考 | 待验收不放行 | 否 |
| 缺所需容差或红线 | 待验收不放行 | 否 |
| 哈希、形状或非有限值异常 | 失败不放行 | 否 |
| 未运行或零数值样本 | 未验收不放行 | 否 |
| 仅完成并列诊断 | 诊断完成，不作放行 | 不提供准入依据 |
