# 计算精度硬性契约

日期：2026-10-10。
状态：规则生效；产品仍有缺口。

## 冻结基线

```text
upstream: google-deepmind/mujoco_warp
revision: 71da24d956378a87a703b6e1442b13aec0c4ac29
```

产品计算精度必须跟随该提交。
规则覆盖全部产品物理路径。
辅助物理探针也须遵守。
上游采用f32时全链保持f32。
上游显式混合精度时逐项跟随。
不得私自升精度或降精度。
不得用更高精度冒充数值等价。

上游float与空间向量采用f32。
相关惯量向量也采用f32。
质量因子与偏置力采用同类类型。
依据：[冻结类型](https://github.com/google-deepmind/mujoco_warp/blob/71da24d956378a87a703b6e1442b13aec0c4ac29/mujoco_warp/_src/types.py#L2387-L2439)、[Warp类型说明](https://nvidia.github.io/warp/v1.13/user_guide/runtime.html#data-types)。

## 必检范围

| 层次 | 必检项 |
| --- | --- |
| 模型与状态 | 设备浮点类型、量化位置与转换规则 |
| 中间缓冲 | 位姿、质心、惯量、速度、力及分解量 |
| 内部计算 | 常量、局部变量、累加、归约与数学函数 |
| 实际内核 | 模板展开类型、内核ABI与设备缓冲宽度 |
| 编译设置 | fast-math、FMA、降精度选项及工具链版本 |
| 公开结果 | 输出类型与转换舍入位置 |

仅保持公开f32接口不算达标。
不得用内部f64规避原生误差。
不得私自采用f16或TF32。
数学重排也须保留误差证据。
规则不要求跨设备逐位相等。
规则要求类型与精度策略一致。
数值容限仍需逐字段冻结。
不同编译器仍需各自验收。

纯参考与诊断可以采用f64。
它们不得反馈产品物理结果。
原生ABI继续按上游映射转换。
时间戳不冒充物理工作区。
通用传输支持f64不构成豁免。
审查者必须追踪实际物理调用。

## 硬性验收指标

| ID | 度量 | 必须达到 |
| --- | --- | --- |
| NP01 | 类型映射率；实际精度偏离数 | 100%；0项 |
| NP02 | 精度证据覆盖率；证据缺失数 | 100%；0项 |
| NP03 | 上游结果对照覆盖率；容限失败数 | 100%；0项 |
| NP04 | 批量对照条件与性能记录缺失数 | 0项 |

覆盖率分母采用本次验收范围。
范围必须列明字段与内核。
未实现功能不进入局部通过分母。
完整产品须覆盖全部目标路径。
原有辅助也不能继续豁免。

NP01同时检查各层类型。
上游f32对应内部f64即为失败。
最终窄化为f32不能消除失败。
NP02记录冻结提交与具体符号。
它也记录生成内核与编译选项。
NP03读取冻结MJWarp静态结果。
参考清单必须冻结模型与状态。
输入须采用相同量化规则。
逐字段先固定误差公式与容限。
不得在失败后放宽容限。
产品测试不启动Python。
离线参考不进入产品运行链。
原生MuJoCo参考另行保留。
它不能替代MJWarp结果对照。

NP04记录相同模型与输入。
它也记录相同世界数与精度。
双方记录GPU与驱动版本。
双方记录预热、同步与计时边界。
记录稳态批量耗时与显存。
冷启动与上传耗时单独报告。
不得用混合精度冒充公平对照。
本规则不虚构固定加速比。
性能目标另按阶段登记。

## 开发与收尾

设计预检必须提交精度映射。
本次变更必须登记适用NP指标。
编码后审查实际生成的内核。
先核对NP01与NP02。
再执行NP03与NP04。
数值测试覆盖debug与release。
功能验收继续覆盖双平台。
缺少环境时明确报告未测项。
精度失败时阻止对应等价验收。
缺少证据时报告精度未验收。
不得用旧辅助通过关闭新指标。
不得把Normify校验当物理验收。

同步物理内核已检查生成PTX。
检查拒绝物理f64与低精度。
检查覆盖实际同步内核。
它不覆盖其他探针后端。
审查者仍须核对全部NP指标。

CUDA的sinf与cosf有慢路径。
它们把整型角度量转换为f64。
Warp也调用同类f32函数。
本项目保留该库级约简。
门禁只接受确切的指令三元组。
它拒绝物理浮点量的升精度。
它也拒绝其他f64运算。
本项不允许私有f64工作区。
依据：[Warp数学接口](https://github.com/NVIDIA/warp/blob/v1.13.0/warp/native/builtin.h#L1179-L1184)。

设置MJWARP_PHYSICS_PTX_DIR后，
编译器记录CUDA源码与PTX。
回执记录哈希与编译参数。
回执也记录NVRTC与门禁结果。
未设置时不写入产物。
