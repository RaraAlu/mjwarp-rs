## 输入与布局

`SparseMassInput`校验原生字段。
它不扩充原惯性九字段。
它独立接收以下整数数组：

```text
dof_parentid
M_rownnz / M_rowadr / M_colind
tree_dofadr / tree_dofnum
```

CSR行按祖先编号升序存放。
每行末项保存对角。
树区间连续覆盖全部自由度。
空树按数量零直接过滤。
过滤不依赖空树地址。
分解大块要求完整祖先前缀。
压缩稀疏大块仍不支持。

元数据跟随冻结`io.py`。
块分类同时检查结构与尺寸。
紧凑块采用地址`-2`。
稀疏块采用地址`-1`。
其余块记录稠密前缀偏移。
标量阈值保持六维。
稠密阈值保持64维。
分支小块不一定走标量路线。
不能仅按尺寸分类。

它构造以下冻结元数据：

```text
qLD_block_adr / qLD_block_total
qLD_updates / qLD_all_updates
qLD_level_offsets
```

每层保留原先枚举顺序。
层编号按祖先深度排序。
空更新采用原占位元组。
宿主只构造整数拓扑。
它不计算任何物理因子。
