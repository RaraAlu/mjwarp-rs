tile_reduce.h定义局部与warp归约。
本轮只读取上游源码。
本轮不启动Python或参考作者。

| 量 | 精度与布局 |
| --- | --- |
| qvel与Mqvel | f32，世界级成对打包 |
| products | f32，lane+reg*32 |
| thread_sum | f32，首项初始化 |
| shuffle sum | f32，默认单warp |
| 半倍常量与结果 | f32，0.5f |
| 势能、当前与暂存输出 | f32 |
| 元数据NV | i32 |
| 模型与状态标签 | 宿主u64，非物理量 |
| 独立数学诊断 | f64，不反馈产品 |

产品先计算寄存器乘积。
局部累加从products[0]开始。
它不先置正零。

尾部无效槽不进入局部累加。
ballot标记有效lane。
shuffle_down按16/8/4/2/1执行。
部分mask沿用原模32条件。
lane0写入半倍动能。
产品不改成串行求和。
产品不增加f64工作区。
产品保留普通C++融合许可。
原fmad与fast-math策略不变。
