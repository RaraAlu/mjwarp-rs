# CRB常驻严格组合

日期：2026-10-14。
本轮落实常驻质量矩阵辅助。
完整CRB与G02仍未验收。

## 计划与实际接口

本轮沿既定[实施计划](implementation-plan.md)。
本轮复用原模块UID。
主前置与资源锁保持。
本轮不启动正式P4排程。
它不需要RNE加速度输出。
RNE失败不阻断该独立位置阶段。
原RNE两类三次账本仍冻结。
本轮没有再次执行RNE测试。

新`MassMatrixPlan`保留设备模型。
新`MassMatrixData`独占设备状态。
旧一次性探针保持独立。
旧探针内核源码保持不变。
更新阶段不重新上传模型。
更新阶段也不重新编译内核。

| 接口 | 实际行为 |
| --- | --- |
| `create_data` | 创建独立位置与矩阵状态；初始未就绪 |
| `update_position` | GPU刷新刚体与质心；废弃矩阵结果 |
| `update_matrix` | 只读已有cinert与cdof；拒绝陈旧前置 |
| `update` | 显式组合两个阶段 |
| `write_qpos` | 检查后写全量位置；废弃前置与矩阵 |
| `write_world_qpos` | 只写指定世界；整组派生结果失效 |
| `readback` | 检查所需前置与矩阵守卫；返回独立快照 |

输入拒绝保留已有结果。
设备写入失败废弃派生结果。
跨计划调用拒绝外来状态。
更新失败不发布旧矩阵。
矩阵阶段不运行空间速度或RNE。
回读不要求未执行的附着阶段。
输出复用`MassMatrixOutput`。
快照在计划与设备状态外存活。

## 精度与上游语义

冻结提交采用`71da24d`。
本轮实读两个生成入口。
它们分别采用以下实际名称：

```text
_crb_accumulate_073a11b8_cuda_kernel_forward
_M_13671fca_cuda_kernel_forward
```

来源与ABI见[映射](evidence/resident-crb/map.json)。
cinert与crb各含十个f32分量。
cdof含六个f32分量。
armature与矩阵采用f32。
局部量与累加也采用f32。
索引与树深采用i32。

新阶段先复制cinert。
它同时清零稠密矩阵。
它按树深反向执行原子加。
每体包含十次浮点原子加。
同步屏障隔开相邻深度。
父体为世界体时，它跳过累加。
此边界保留不同子树质心坐标。

惯量乘cdof的首积分组独立。
分量1先舍入`i1*v1`。
随后融合`i3*v0`。
本轮不套用RNE加速度的分组。
实际PTX保留六次点积融合。
首项明确加正零。
对角线先写armature。
点积完成后再执行原子加。
本轮不以armature初始化点积。
四个次正规边界用例通过。
它们核对全局浮点原子行为。

输出采用对称稠密行布局。
它按自由度祖先链填充矩阵。
镜像复制原子操作后的实际值。
该布局不冒充上游M的存储ABI。
armature仍只共享一行。
零自由度跳过矩阵填充内核。
它仍计算crb与检查守卫。
本轮不叠加肌腱惯量。
它不提供完整休眠或质量求解。

产品采用12.8.93及compute_70。
冻结产物采用12.9.86及sm_89。
双方保留融合与非快速数学。
三项新内核通过实际f32门禁。
这不证明全部机器指令等价。
