# 关节被动力生产者

日期：2026-10-15。
范围：P4、U038、G04子集。
本轮不交付完整被动力。

## 实际实现

代码位于以下路径。

```text
src/physics/smooth_force/joint_passive.rs
```

公开接口如下。

```rust
JointPassivePlan
JointPassiveData
JointPassiveOutput
JointPassiveOptions
JointPassiveParameters
```

计划读取实际运动学拓扑。
数据绑定同一计划身份。
相同形状不代表同一计划。
五项参数各自保留批量周期。
构造后暂不支持参数热更新。

| 参数 | 每批宽度 |
| --- | --- |
| `qpos_spring` | `nq` |
| `stiffness` | `njnt` |
| `stiffness_poly` | `2*njnt` |
| `damping` | `nv` |
| `damping_poly` | `2*nv` |

四类关节均支持DOF阻尼。
自由关节覆盖六个DOF。
球关节覆盖三个DOF。
滑动与铰链各覆盖一个DOF。
四类关节均支持弹簧。
自由关节先处理平移。
它再处理四元数旋转。
球关节处理四元数旋转。
禁用弹簧会忽略全部系数。

状态支持整批与单世界写入。
合法写入废弃对应就绪状态。
非法长度或非有限数不改状态。
输出持有独占宿主快照。
快照不认证未来物理状态。

多项式保持以下算序。

```text
poly = linear
poly += a*x
poly += (b*x)*x
damper = -v * poly(d, a, b, abs(v))
spring = -dif * poly(s, a, b, dif)
```

首轮标量样本使用二进制有理数。
标量参考先断言f32精确表示。
参考不读取候选中间结果。
标量仍要求零位差。

本轮不移植或放宽旧容差。

该连接不下载后回传物理力。

该数字不代表测试命令数。
它也不代表内核启动总数。
本轮不重判旧四力验收。
