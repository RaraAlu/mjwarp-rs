## 内核门禁

同步物理编译器检查生成PTX。
门禁只在编译阶段运行。
常驻更新不重复解析PTX。
门禁拒绝物理f64运算。
门禁也拒绝f16、BF16与TF32。
它不只检查公开指针类型。
通用传输ABI测试保留f64。
测试专用编译跳过物理检查。
产品编译始终运行物理检查。

CUDA的sinf与cosf有慢路径。
它们用f64约简整型角度量。
Warp的f32接口也调用它们。
本项目保留该库级行为。
门禁只接受确切的约简三元组。
它拒绝物理浮点量的升精度。
它也拒绝其他f64运算。
本轮不声称全部PTX没有f64。
依据：[Warp数学接口](https://github.com/NVIDIA/warp/blob/v1.13.0/warp/native/builtin.h#L1179-L1184)。

```text
cvt.rn.f64.s64 temporary0, integer;
mul.rn.f64 temporary1, temporary0, 0d3BF921FB54442D19;
cvt.rn.f32.f64 result, temporary1;
```

普通f64累加仍触发拒绝。
不同常量或断开的链也触发拒绝。
工具链变化可能触发门禁。
维护者须核对库实现后再调整。
不得改用快速三角函数绕过门禁。
