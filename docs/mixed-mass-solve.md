# 常驻三路混合求解

日期：2026-10-14。
本轮消费同代混合因子。
它求解稀疏(Sparse)大树。
它也求解小块(Small)前缀。
它还求解紧凑(Compact)块。
它支持独立批量右端项(RHS)。
它仍拒绝全部Tile块。
它没有接通CRB混合桥接。
七维SDK二进制仍不准入。
本轮不绕过原PTX精度门禁。

## 新产品接口

新增以下公开类型：

```text
SparseMassMixedSolvePlan
SparseMassMixedSolveData
SparseMassMixedSolveOutput
SparseMassMixedSolveWorld
```

计划复用[三路混合分解](mixed-mass-factor.md)。
调用方写入主CSR矩阵与RHS。
完整更新依次采集、分解、求解。
结果包含同代因子、RHS与解。
RHS与解按世界、RHS、DOF排列。
每世界只保存一份合并因子。
快照独占宿主结果与模型引用。
它不依赖计划或设备缓冲寿命。

## 算子与编译映射

冻结`solve_LD`先处理块。
随后稀疏阶段只写标记-1的槽。
旧稀疏内核会改全部非稀疏槽。
直接复用会覆盖Small结果。
本轮保留旧内核字节。
本轮实现独立三路消费内核。

| 路线 | 实际处理 |
| --- | --- |
| Small2至6 | 静态模板；每线程独占完整块；两次三角代入 |
| Compact | 对角倒数乘RHS |
| Sparse | 仅自身槽复制；UP、对角乘法、DOWN |

Small两次除法均采用f32。
实际操作为`div.rn.f32`。
它不采用倒数乘法替代。
乘减保留`mul.f32/sub.f32`。
编译器仍可以融合乘减。
本轮不强制提前执行FMA。
Sparse采用f32乘法与原子减。
每层更新均完成线程同步。
三路从不覆盖彼此的自由度。

本轮核对冻结CUDA调用。
它调用`wp::div(float,float)`。
底层实现返回`a/b`。
原1与2维PTX也含div.rn。
2维还包含无.rn的乘减。
缓存文件采用`.sm89.ptx`后缀。
初查误用`.ptx`名称。
本轮只读修正查找结论。
它没有重编译旧产物。
3至6维冻结机器对应仍缺。

输入、输出与中间量采用f32。
元数据与路由采用i32。
新128线程ABI接收完整因子跨度。
该跨度包含U前缀、CSR与倒数。
原128、256与64方法保持。
原编译与精度门禁也保持。

| 实际编译项 | 值 |

| NVRTC | 12.8 |

| fmad | true |

全部29份运行回执通过门禁。
该数字表示入口捕获数。
它不表示29种不同内核模块。

局部门禁不证明完整NP等价。

## 缓存与失败边界

合法矩阵写使全部阶段失效。
合法RHS写只使解失效。
RHS更新保留因子全部位型。
非法长度、世界或NaN保留缓存。
外来计划也拒绝且保留缓存。

求解只消费完成的合并因子。
它不重读旧主M或生产者CSR。
它也不依赖旧Small生产者。
它仍检查合并因子全部有限值。
它检查各路线的正主元。
它也检查全nv的正倒数。
GPU先验证因子与RHS守卫。
因子异常使因子缓存失效。
RHS异常保留因子但拒绝求解。
所有失败都禁止整批发布。
调用方可以修复后重算。
结果与状态缓冲各保留守卫。
新ABI检查四会话与容量。
它也检查维度、跨度与组数。
私有调用方证明元数据界限。

| 拓扑 | 独立来源 |
| --- | --- |
| mixed86 | 原65链M与LU解；原Small2至6矩阵；Compact矩阵4 |
| crowded390 | 131链`diag(d)+0.0625*11T`；129个Small2；Compact矩阵4 |

普通拓扑复用既有LU原输出。
新块先选择已知解z。

它断言新RHS能精确映射f32。
拥挤拓扑全部采用独立已知z。
两拓扑各包含两态与三列RHS。
列覆盖零、交替序列与固定种子。
原生65链保留原LCG列。
新块采用粗dyadic制造解。
参考f64只服务纯诊断。
它不反馈产品物理结果。

装配最大整体残差为1.7533e-18。
整体分母可能掩盖小量级树。
本轮产品验收逐树计算残差。
它不让高范数Small稀释Sparse误差。
每树仍采用原容差2e-5。
逐元素仍采用原abs/rel2e-4。
