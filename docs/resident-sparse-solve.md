# 常驻稀疏融合回代

日期：2026-10-14。
范围：G03辅助原型。
完整产品验收仍开放。

## 实现与精度

入口采用`SparseMassSolvePlan`。
数据采用`SparseMassSolveData`。
独立快照保留因子与解。
接口复用常驻CRB与CSR。
RHS更新只废弃解。
qpos更新废弃下游缓存。
外来计划先拒绝，再保留缓存。
非法输入也保留合法缓存。

元数据全用`i32`。
物理字段全用`f32`。
中间量与原子累加也用`f32`。
回代不提升精度。
每世界每RHS独占一个块。
每块采用128个线程。
反层阶段执行原子减法。
对角阶段执行单精度乘法。
正层阶段再次执行原子减法。
每层执行全块屏障。
乘法采用`__fmul_rn`。
原子减法采用取负与原子加。
紧凑块独立执行`D*y`。
非紧凑混合块仍明确拒绝。
纯紧凑非空输入也仍拒绝。
零自由度路径保留守卫。

新入口固定128线程。
旧通用入口仍采用256线程。
旧入口源码保持逐字一致。
新入口检查四缓冲会话。
它也检查维度与容量。
私有调用方证明元数据界限。

回代前仅回读诊断状态。
设备验证因子与RHS。
宿主不回传产品物理量。
读回仅检查缓存因子与解。
它不再检查陈旧CRB或CSR。
它仍检查全部有限值。
它也检查正主元与正逆对角。
各浮点缓冲保留双端守卫。

编译保留FMA，关闭快速数学。

数值测试覆盖12批。

世界数采用1、2、257。
默认RHS数为3。

每状态覆盖两次RHS流。

缓存因子位型保持不变。
本轮不重跑旧重构验收。

阶段耗时合计1217毫秒。
该值包含宿主比较。
它不能证明公平性能。
新增设备缓冲最多432904字节。
