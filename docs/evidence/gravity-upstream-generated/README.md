# 冻结上游重力设备证据

本目录记录真实启动。
内核来自冻结上游。
Rust直接加载固定PTX。
产品测试不启动Python。

`gpu-1/raw.json`先存位型。
它早于有限值判定。
`gpu-1/run.json`记录比较。
原容差保持2e-6。
`input-bits.json`记录输入位型。
它来自事后静态重建。
`comparison.json`比较已存输出。
`executions.json`归档命令回执。

结果共含二十八项。
二十六项位型一致。
两项相差四个ULP。
最大误差为1.1920928955078125e-7。
真实核与候选逐位一致。
真实核与转写桥逐位一致。

候选链提供质心。
候选链提供自由度。
完整链仍不独立。
本证据不关闭NP01至NP04。
