## 内部量分母

本轮固定17组映射。
分组不是全部局部变量计数。
每组记录实际类型及表达式。
产品与外部来源均绑定哈希。
检查器拒绝缺项和类型改写。

| 分组 | 数量 | 主要内部量 |
| --- | --- | --- |
| 数学辅助 | 四组 | 正长度归一化、四元数乘法、旋转和矩阵 |
| 自由关节与mocap | 两组 | 局部位置和四元数 |
| 父体与关节坐标 | 三组 | 父体组合、锚点和轴 |
| 关节增量 | 三组 | 滑动位移、球关节四元数、铰链半角 |
| 姿态累加与修正 | 三组 | 旋转乘积、偏心补偿、末次归一化 |
| 惯性位姿 | 两组 | 惯性位置和矩阵 |

物理标量与局部数组保持f32。
平方和、点积及乘积保持f32。
铰链半角采用f32常量。
正弦和余弦采用单精度函数。
地址与循环变量仍采用整数。

旋转求值顺序差异继续保留。
偏心补偿也采用不同表达式。
本库采用缩放负一后相加。
上游采用向量相减。
本轮不将同型判作逐位一致。

本库按世界串行遍历体。
上游按分支组织体遍历。
本库同时计算矩阵与惯性位姿。
上游另行启动两个阶段。
本轮仅登记调度与中间存储差异。

## 零四元数阻断

冻结源码存在三方差异：

| 来源 | 零长度分支 |
| --- | --- |
| 本库完整入口宏 | 返回四分量全零 |
| Warp原生四元数头文件 | 返回四分量末位一 |
| Warp注册文档 | 宣称返回零四元数 |

这里按四分量存储顺序描述。
不将末位一称作MJWarp单位旋转。
Warp字段名不等于物理分量名。

证据定位如下：

- 本库：`KINEMATICS_CUDA`的`normalize`。
- Warp：`native/quat.h`的归一化分支。
- Warp：注册文件`builtins.py`的四元数重载。
- Warp：`native/builtin.h`的零阈值。
- 冻结MJWarp：`_kinematics_branch`的调用。

外部路径以清单为准。
它们不属于本库源码目录。

完整入口只检查状态长度及有限值。
该检查不排除零四元数。
严格辅助探针另有范数限制。
两类入口不能混为同一输入域。

本轮没有运行上游生成内核。
因此只确认源码分歧。
本轮不新增GPU数值结论。
本轮不修正归一化公式。
检查器禁止删除或放行该阻断。
它同时保持等价资格为假。
历史数值通过不能豁免此项。

## 七项输出

| 字段 | 设备标量 | 宿主视图区间 |
| --- | --- | --- |
| `xpos` | f32向量 | `0..3*nb` |
| `xquat` | f32四元数 | `3*nb..7*nb` |
| `xmat` | f32矩阵 | `7*nb..16*nb` |
| `xipos` | f32向量 | `16*nb..19*nb` |
| `ximat` | f32矩阵 | `19*nb..28*nb` |
| `xanchor` | f32向量 | `28*nb..28*nb+3*nj` |
| `xaxis` | f32向量 | `28*nb+3*nj..28*nb+6*nj` |

区间相对单世界有效载荷。
整组缓冲两端各有四个保护槽。
四元数采用wxyz存储。
矩阵采用行优先展开。

检查器核对设备指针及写入。
它也核对宿主声明及视图区间。
上游输出声明与写入一并实核。
回读保持f32，不重算物理量。

只读有限值诊断会转换到f64。
该诊断只决定错误返回。
它不回写物理结果。
本轮单列该允许的诊断边界。

完整入口保留已有世界体位姿。
它仍重算世界体派生矩阵。
上游分支列表不包含世界体。
上游矩阵阶段覆盖全部体。
本轮不扩展世界状态语义结论。
