# M3稀疏质量对角证据

## 范围

- 本切片只迁移对角入口。
- 目标是`sparse_mass_diag`。
- 产品调用只有一处。
- CUDA源码保持原状。
- 编译选项保持原状。
- f32路径保持原状。
- 调用顺序保持原状。

## 类型化契约

- ABI含四个指针槽。
- ABI含四个标量槽。
- 线程块固定为256。
- 共享内存固定为零。
- 元数据槽承载地址。
- 它要求可信索引证明。
- 元数据保留完整打包。
- 前两项保存nv和nc。
- 中段保存稀疏行布局。
- 尾段保存更新三元组。
- 包装核对设备会话。
- 包装核对写入别名。
- 包装拒绝跨度增减。
- 包装拒绝整数上溢。

容量公式如下：

```text
metadata = packed metadata words
unused = worlds * nc + 8
unused2 = worlds * nc + 8
output = worlds * (nc + nv) + 8
first = 0
count = 0
stride = nc + nv
work = worlds * nv
```

两个只读槽可同址。
它们继续引用矩阵。
输出槽支持读写。
输出槽拒绝只读重叠。

## 对角约束

- 对角地址来自行布局。
- 每行末项就是对角。
- 写入区位于因子之后。
- nv为零时不发射。
- 保留维度必须为零。
- 工作量必须完全匹配。

## 执行顺序

1. Copy先完成同步。
2. Update逆层运行。
3. Diag最后运行。
4. 宿主检查完整结果。
5. 最后发布就绪状态。

拒绝不会发布结果。
恢复沿用同一计划。
