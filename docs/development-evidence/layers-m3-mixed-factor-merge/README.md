# M3混合因子合并证据

## 范围

- 本切片只迁移合并入口。
- 目标是`mixed_factor_merge`。
- 产品调用只有一处。
- CUDA源码保持原状。
- 编译选项保持原状。
- f32路径保持原状。
- 生产者顺序保持原状。

## 类型化契约

- ABI含四个指针槽。
- ABI含四个标量槽。
- 线程块固定为256。
- 共享内存固定为零。
- 元数据指针没有读取。
- 它使用普通值槽。
- 它不使用元数据证明。
- 包装核对设备会话。
- 包装核对写入别名。
- 包装拒绝跨度增减。
- 包装拒绝整数上溢。

容量公式如下：

```text
metadata = 1
small = worlds * prefix + 8
sparse = worlds * (nc + nv) + 8
output = worlds * (prefix + nc + nv) + 8
work = worlds * (prefix + nc + nv)
```

前后各保留四项守卫。
零前缀仍属合法输入。
CSR尾和DInv保持连续。

## 执行顺序

1. Small生产者先完成。
2. Sparse生产者再完成。
3. 包装校验全部绑定。
4. 同步内核完成复制。
5. 宿主检查合并结果。
6. 最后发布就绪状态。

拒绝不会发布新结果。
恢复沿用同一个计划。

GPU边界测试复用一份计划。

它也核对输出守卫。

它检查1236040个槽位。
最大绝对误差为3.56e-6。
最大重构误差为5.69e-7。

数值容差保持如下：

```text
abs(actual - reference) <= 2e-4 + 2e-4 * abs(reference)
abs(reconstructed - M) / max(abs(M), 1) <= 2e-6
```

产品实际值保持f32。
参考与诊断使用f64。
3.56e-6只是本次观测。
它不构成全局精度验收。

参考来自两份夹具：

```text
fixtures/sparse-mass-factor/native.json
fixtures/small-mass-prefix/reference.json
```

它们覆盖原生稀疏因子。
它们也覆盖Small解析。
它们不证明完整MJWarp等价。

两次GPU运行各用新目录。
每个目录含十二个入口。
每个入口仅保留三份文件。
