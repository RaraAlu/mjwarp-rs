# M3常驻混合聚集证据

## 范围

- 本切片只迁移聚集入口。
- 校验入口保持现状。
- CUDA源码保持原状。
- 编译选项保持原状。
- 容差与夹具保持原状。

目标入口如下：

```text
resident_mixed_gather(
  const int* meta,
  const float* source,
  const float* unused,
  float* csr,
  unsigned nb,
  unsigned n,
  unsigned nc,
  unsigned work
)
```

## 类型化契约

- 包装绑定四个指针槽。
- 包装绑定四个标量槽。
- 包装固定256线程。
- 包装核对真实设备跨度。
- 包装核对设备会话。
- 包装拒绝写读重叠。
- 包装拒绝陈旧元数据。
- 包装拒绝网格上溢。
- 包装拒绝整数上溢。

元数据必须满足以下约束：

- 行区间连续且完整。
- 每行至少包含一项。
- 列索引严格递增。
- 每行末项对应对角线。
- 所有列索引都合法。

工作量公式如下：

```text
work = worlds * n
```

源容量公式如下：

```text
worlds * (10 * nb + n * n) + 8
```

输出容量公式如下：

```text
worlds * nc + 8
```

## 发布顺序

执行路径保持以下顺序：

1. 核对数据归属。
2. 清除发布状态。
3. 执行既有校验。
4. 检查源与守卫。
5. 核对元数据证明。
6. 执行类型化聚集。
7. 检查输出守卫。
8. 发布聚集完成。

聚集失败停止分解。
聚集失败停止求解。
聚集失败阻止回读。
