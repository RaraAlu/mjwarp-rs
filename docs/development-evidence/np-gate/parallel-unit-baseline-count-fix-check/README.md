## 5. 发现

### 低

  数值/结构无问题，属证据描述误差；建议下一轮文档勘误时改为「28 条内容行（31 行含标题/空行）」或直接不写计数。
- **L2 U-CALL 口径与合并表不一致（可能误导复算）**：附录第 6 行写「U-CALL 在**设备函数体内**按 API 调用点计数」；
  合并表 §2.1 定义是「调用点：`wp.xxx(` 出现次数（注释、docstring 内的不计）」，**不限设备函数体**——
  `B.1`/`B.5`/`L.3` 等多为宿主侧调用。建议改为「按 `wp.xxx(` 出现次数（宿主与设备侧均计；注释/docstring 不计）」。
- **L3 不可复现项被笼统写成「文本匹配或约数」**：附录第 19 行把 `B.6 237`、`D.1 698`、`I.5 19种255处` 一并写「按文本匹配或约数处理」；
  合并表 §1 这三行结论分别是「**未定**（候选 113/179/265）」「**仍不成立**（U-BODY **726**，差 28）」「**仍不成立**（**23 种 287 处**，差 32/4）」。
  读者可能误以为旧值可继续沿用；建议补一句「这三项定稿值/状态见合并表 §1（B.6 未定；D.1 726；I.5 23 种 287 处）」。
