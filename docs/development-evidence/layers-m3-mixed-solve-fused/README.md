# M3混合融合求解证据

## 范围

- 本切片只迁移融合求解。
- 校验CUDA保持原状。
- 校验ABI保持原状。
- 共享元数据增加证明。
- 私有启动实现保持原状。
- 运行时内核文件未变。
- CUDA源码保持原状。
- 编译选项保持原状。
- 容差与夹具保持原状。

目标入口如下：

```text
mixed_solve_fused(
  const int* meta,
  const float* rhs,
  const float* factor,
  float* output,
  unsigned n,
  unsigned stride,
  unsigned nr,
  unsigned worlds
)
```

## 类型化契约

- 包装绑定四个指针槽。
- 包装绑定四个标量槽。
- 包装固定128线程。
- 包装固定零共享内存。
- 包装核对设备会话。
- 包装核对写入别名。
- 包装拒绝陈旧元数据。
- 包装拒绝整数上溢。
- 包装拒绝网格上溢。

元数据证明以下内容：

- 证明绑定宿主快照。
- 证明绑定设备跨度。
- 证明绑定写入代际。
- 证明完整元数据长度。
- 证明层偏移连续递增。
- 证明更新索引有效。
- 证明稀疏地址有效。
- 证明同层读写分离。
- 允许同层同目标归约。
- 证明Small区域互斥。
- 证明前缀完整连续。
- 证明路由标记匹配。
- 证明零更新占位边界。

容量公式如下：

```text
metadata = exact host snapshot length
rhs = worlds * n * nr + 8
factor = worlds * stride + 8
output = worlds * n * nr + 8
groups = worlds * nr
```

包装拒绝容量增减。
包装拒绝跨会话缓冲。

## 执行顺序

构造阶段保持以下顺序：

1. 上传完整元数据。
2. 编译校验入口。
3. 编译融合入口。

求解阶段保持以下顺序：

1. 清除求解发布。
2. 检查分解发布。
3. 执行类型化校验。
4. 读取校验状态。
5. 执行类型化求解。
6. 检查求解结果。
7. 发布求解完成。

包装拒绝不会写输出。
包装拒绝不会发布结果。
恢复后继续原数值路径。
