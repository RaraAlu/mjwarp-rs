# G-L2 validation-window plan (S-3a summary; single attempt, fail-stop)

- Window: ONE validation window (G-L2), single attempt, fail-stop, no retry.
- Executor: Backend (sole writer; repo-write-lock owner=Backend during the window). Arch: read-only design/peer
  evidence. QA: material pre-review + post-window review.
- Spec basis: signed spec v3 sha256 bb064fe0a85ab38abba8043768666a0d9f73fc53d9f2f3dd72eace060c8a924d / 39,379 B (sections 10.1, 10.2, 4-6, 8, 9.3, 12 G-L2).
- Reference under validation: fixtures/render-bvh/scene-a-light/perworld/nw3-light-hinge02040/ (five files,
  measured total 11,078,239 B: rgb 5,531,026 / depth 1,844,650 / seg 3,687,826 / state 2,486 / capture.json 12,251).
- Entities: 12 frozen executables = the 11 perworld-suite entities (enumerated from the old guards JSON, not
  copied from prose) + render_per_world_light.
- Guard inputs: 83 existing + 10 mandatory new = 93 (optional 0); outline lists: 2 criterion v2.2 arms.
- Guards JSON: scripts/validate/render-bvh/guards-perworld-l2-light.json (written by the freezer at -Execute).
- Criteria: A (per-world pixel equality, both cameras), B (light field bit equality), C (C1/C2 >=576 both pairs;
  384 acceptance floor; [384,576) stop, <384 refuse).
- Compile regime: the freezer -Execute is the only build point (cargo test --no-run exit 0, cargo-artifacts.jsonl
  kept); zero compile inside the window body.
- Freeze timing: after the regular monitor passes and before the body; frozen exe triple check live == guard == stash.
- Single run; any failure: stop, report the user, keep the scene, no retry, no threshold/reference/camera change,
  never swap a frozen executable.
- Out of scope: no re-authoring, no new reference, no AA / single-launch performance, no product-vs-reference
  comparison beyond the frozen suites.
