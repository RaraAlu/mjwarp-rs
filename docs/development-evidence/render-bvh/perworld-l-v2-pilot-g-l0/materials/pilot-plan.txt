## 2. Decision rule (spec section 6, written here verbatim in intent)

For adjacent world pairs (0->1, 1->2), computed on the reference side:

- **C1 (light-driven, `cam-persp`)**: `rgb_changed_px` = pixels with `max_channel |delta rgb| >= 1/255`.
- **C2 (geometry-driven, `cam-hinge`)**: `depth_changed_px` (f32 bit patterns differ) and
  `seg_changed_px` (`(object_id, object_type)` pair differs).

Verdict (both sets, both pairs):

| Condition | Verdict | Action |
| --- | --- | --- |
| C1 >= 576 both pairs AND C2 depth >= 576 both pairs AND C2 seg >= 576 both pairs | **pass-margin** | report; pilot succeeded; S-2 may follow |
| any of the counters in [384, 576) | **insufficient** | STOP, report Chief/user; no threshold change |
| any of the counters < 384 | **non-discriminating** | STOP/refuse to pass, report Chief/user |

Diagnostics (record only, never judged, never substituted for C1/C2):
`cam-persp` depth/seg change counts expected 0/0 (scene geometry fact, spec 3.2);
`cam-hinge` rgb change counts expected large (geometry + light).

Expected order of magnitude (CPU predictions from spec 3.3/3.4, not measurements):
C1 ~55,581/55,839; C2 depth ~35,812/33,947; C2 seg ~16,041/16,755.

## 3. Fail-stop rules

- Any capture error, missing env, metadata mismatch, refit-counter mismatch, non-zero readout exit,
  baseline/monitor failure, or tree dirty => STOP immediately.
- Do not retry, do not change thresholds/camera/recipe, do not delete evidence, do not commit npz.
- Keep the temp pilot tree under `target/` for the report; the pilot is NOT committed as a reference.
- Only after a pass-margin verdict: copy the evidence files listed in `evidence-checklist.txt` into the
  pilot evidence directory (a separate pilot card), still without committing npz.
