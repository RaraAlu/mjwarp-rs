# G-L1 monitor plan (pre-window; run before capture, after baseline)

Command (regular thresholds, no exception):
  powershell -NoProfile -ExecutionPolicy Bypass -File scripts/validate/render-bvh/monitor-until-clean.ps1 -Required 60 -MaxMinutes 30 -MaxUtil 40 -OutCsv target/render-bvh/perworld-l-v2-gl1/monitor.csv

Rules:
- longest_clean must reach 60 (required) and the process must exit 0.
- util < 40 % on all 60 clean samples (regular). External loads are recorded, not waited on indefinitely (> MaxMinutes -> stop).
- free >= signed floor on every sample (operator-enforced; script internal floor is 10,240 MiB only).
- build process count 0; no task CUDA compute process on the clean samples.
- Exception (only if S-2 pre-approved authoring exception): rerun with -MaxUtil 60; record every sample,
  exception_load_bearing=true, free >= signed floor still required; a 60-threshold pass must not be
  reported as a regular util<40 pass.
- CSV copy goes into the evidence directory (window/monitor.csv).
