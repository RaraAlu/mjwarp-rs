语义层指标（同一编译器的产物对比）
  tex.level.2d.v4.f32.f32 取样指令：baseline 1 条 → current 2 条（+1，恰为天空盒取样）
  `and.b32 %r, %r, 512`（flag bit9=0x200 判定）：baseline 0 条 → current 1 条（+1）
    · baseline 中出现的 2 处 `512` 均为 `.local __local_depot0[512]` / `add.u64 %rd, %SPL, 512`，与本位无关
  max.f32：39 → 40（+1，`t` 上夹）；min.f32：9 → 10（+1，`t` 下夹）
  sqrt：51 → 51（无新增超越函数）
  新增取样指令与新增 512 位判定唯一出现处 = 内核新增的天空盒背景分支（见 README §6 控制流论证）
