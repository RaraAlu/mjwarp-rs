# guards aggregate 的可复算口径（审计项）与只读复算脚本

## 口径（必须与 `freeze-guards.ps1` 一致）

```text
aggregate = sha256( concat( sha256_hex(entry_i) for entry_i sorted by repo-relative path ) )
排序：PowerShell `Sort-Object { $_.path }`，即 culture / case-insensitive 排序。
拼接：73 个 sha256 十六进制串直接相连、无分隔符；对 ASCII 字节求 sha256、小写十六进制。
```

## 为什么不能用序数排序复算（审计注意）

`Sort-Object { $_.path }` 是 culture/case-insensitive：同一批 73 项里，`README.md` 会排在
`context.json` 之后（case-insensitive 比较 'r' > 'c'）。用**序数排序**（如 Python `sorted()`）会得到
另一种顺序：

- 首个顺序差异位置 index=3：序数 `fixtures/.../reference/README.md`、culture `fixtures/.../reference/context.json`
- 同一烟测 JSON 用序数排序复算得到 `89895a621bd154122c9f4e19d8b67f825309397019215b35b117566a11b0007b`
  **≠ 记录值** `7d24f036…` ⇒ **序数排序不作为复算口径**。
