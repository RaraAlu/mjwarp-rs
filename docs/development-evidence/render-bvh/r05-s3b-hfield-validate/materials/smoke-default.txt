## aggregate 可复算（按脚本自身算法）

复算脚本（PowerShell，与 `freeze-guards.ps1` 同算法：对 73 项按 `path` 排序后拼接 sha256 十六进制串再 sha256）：

```powershell
$g = (Get-Content 'target/render-bvh/r05-s3b-window/guards-smoke-default.json' -Raw) | ConvertFrom-Json
$all=@(); foreach ($e in $g.frozen_exes) { $all += [pscustomobject]@{ path=$e.path; sha256=$e.sha256 } }
foreach ($e in $g.guard_inputs) { $all += [pscustomobject]@{ path=$e.path; sha256=$e.sha256 } }
$sorted = @($all | Sort-Object { $_.path })
$hexConcat = ($sorted | ForEach-Object { $_.sha256 }) -join ''
[BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash([Text.Encoding]::ASCII.GetBytes($hexConcat))).Replace('-','').ToLower()
```

实测：**复算 = `7d24f036…` = 记录值**（match=true）。

> 复算注意：`Sort-Object { $_.path }` 是 **culture/case-insensitive** 排序（例如 `README.md` 排在
> `context.json` 之后）；用**序数排序**（如 Python `sorted()`）会得到不同顺序、aggregate 不复现。
> 本烟测已验证该差异点并采用 PowerShell 同算法复算。
