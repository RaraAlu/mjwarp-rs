# Rust 侧硬件 FMA 全量复现（QA 探针；1003 条 × 9 元素 = 9027 项）

探针源码：`hw_fma_probe.rs`。它与生产实现的关系：

- 生产：`src/render/kernel/cast.rs::warp_quat_to_mat` → `crate::math::fma::fma_f32`
  → `is_x86_feature_detected!("fma")` 为真时内联 `vfmadd231ss`（本机为真，探针里 `is_x86_feature_detected!("fma")` 断言通过）；
- 探针：`_mm_fmadd_ss(a,b,c)`（= `vfmadd231ss` 的 intrinsic 形式），**同一条指令**、同一表达式序。
- 因此探针在「指令语义 + 表达式序」层面等价于生产路径；crate 内部函数本身由
  `derived_contraction_matches_upstream_gpu_bits` 单测（4 案例）覆盖。

## 输入

`target/qa-cam-fma/quats.txt` = 已提交证据 `materials/gpu-reference-digest.json` 的 `quat_bits`（1003 行，
1003 行 × 4 个 hex；前 3 条 = hfield cam0 / hfield cam1 / scene-a cam0，其余 = `numpy.random.default_rng(20261029)`）。
对照 = 同一 JSON 的 `mat_bits`（1003 行 × 9 个 hex）= pinned GPU 链参考。
