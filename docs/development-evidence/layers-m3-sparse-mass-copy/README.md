# M3稀疏质量复制证据

## 范围

- 本切片只迁移复制入口。
- 目标是`sparse_mass_copy`。
- 产品调用只有一处。
- CUDA源码保持原状。
- 编译选项保持原状。
- f32路径保持原状。
- 调用顺序保持原状。

## 类型化契约

- ABI含四个指针槽。
- ABI含四个标量槽。
- 线程块固定为256。
- 共享内存固定为零。
- 元数据槽承载地址。
- 它要求可信索引证明。
- 元数据保留完整打包。
- 首两项保存nv和nc。
- 后续内核共享其余项。
- 包装核对设备会话。
- 包装核对写入别名。
- 包装拒绝跨度增减。
- 包装拒绝整数上溢。

容量公式如下：

```text
metadata = packed metadata words
matrix = worlds * nc + 8
unused = worlds * nc + 8
output = worlds * (nc + nv) + 8
stride = nc + nv
work = worlds
```

两个只读槽可同址。
它们继续引用矩阵。
写槽不得重叠读槽。

空模型仍保持合法：

```text
nv = 0
nc = 0
stride = 0
work = worlds
```

空循环不写有效区。
前后守卫保持原值。

## 执行顺序

1. 包装先校验绑定。
2. Copy同步完成。
3. Update按原序运行。
4. Diag按原序运行。
5. 宿主检查完整结果。
6. 最后发布就绪状态。

拒绝不会发布结果。
恢复沿用同一计划。
