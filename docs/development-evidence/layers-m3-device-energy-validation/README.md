# M3设备动能校验证据

## 范围

- 任务：`2026-10-18-layers-m3-device-energy-validation`
- 父任务：`2026-10-18-layers-m3`
- 源校验改用受控计划。
- 标量校验复用受控包装。
- 真实更新路径不再直接启动通用内核。

## 绑定内容

- 构造器只接收会话和静态`nv`。
- 构造器固定CUDA源码和入口。
- 计划绑定真实设备跨度。
- 计划检查会话和容量。
- 计划检查读写别名。
- 计划检查元数据代际。
- 计划固定256线程校验块。
- 参数顺序保持四指针四标量。

## 产物一致性

`kernel-comparison.json`记录三组比较。
两组覆盖源校验静态维度。
一组覆盖标量校验路径。
三组CUDA源码散列一致。
三组PTX散列一致。
捕获元数据也逐字节一致。
历史目录保留原始CU和PTX。
本目录不复制相同大文件。
