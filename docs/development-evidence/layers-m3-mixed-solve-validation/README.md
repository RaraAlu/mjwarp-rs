# M3混合求解校验证据

## 范围

- 本切片只迁移校验入口。
- 求解入口保持原状。
- CUDA源码保持原状。
- 编译选项保持原状。
- 容差与夹具保持原状。

目标入口如下：

```text
mixed_solve_validate(
  const int* meta,
  const float* rhs,
  const float* factor,
  float* status,
  unsigned n,
  unsigned stride,
  unsigned nr,
  unsigned worlds
)
```

## 类型化契约

- 包装绑定四个指针槽。
- 包装绑定四个标量槽。
- 包装固定256线程。
- 包装核对真实设备跨度。
- 包装核对设备会话。
- 包装拒绝写读重叠。
- 包装拒绝陈旧元数据。
- 包装拒绝整数上溢。
- 包装拒绝网格上溢。

元数据证明以下区域：

- 对角索引都在跨度内。
- D区间都在跨度内。
- 证明绑定宿主快照。
- 证明绑定设备跨度。
- 证明绑定写入代际。

容量公式如下：

```text
metadata = actual host snapshot length
rhs = worlds * n * nr + 8
factor = worlds * stride + 8
status = worlds + 8
```

包装拒绝容量增减。
包装拒绝跨会话缓冲。

## 执行顺序

路径保持以下顺序：

1. 上传完整元数据。
2. 编译校验入口。
3. 编译求解入口。
4. 清除求解发布。
5. 检查分解发布。
6. 执行类型化校验。
7. 读取校验状态。
8. 执行原始求解。
9. 检查求解结果。
10. 发布求解完成。

分解故障清除两级发布。
RHS故障只阻止求解。
恢复后继续原数值路径。

代码保留四类状态分支。
本轮分别注入两类故障。
本轮未单独注入状态三。
