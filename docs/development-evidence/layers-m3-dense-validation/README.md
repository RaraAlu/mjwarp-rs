## 真实接口

冻结入口为：

```text
sparse_dense_validate(
  const int* sources,
  const float* matrix,
  const float* unused,
  float* status,
  unsigned nc,
  unsigned prefix,
  unsigned reserved,
  unsigned worlds
)
```

`sources`未被内核读取。
`unused`未被内核读取。
`prefix`未被校验读取。
`reserved`必须保持为零。
内核读取矩阵载荷。
内核读取两端守卫。
内核写入世界状态。
