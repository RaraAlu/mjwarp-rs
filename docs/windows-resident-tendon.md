## 输出与兼容

快照提供全局肌腱结果。

全局输出独立拥有宿主缓冲。

公开浮点结果保持f32。
旧固定与空间输出保持局部编号。

| 字段 | 布局 |
| --- | --- |
| `ten_length` | 每世界`ntendon`值 |
| `ten_jacobian` | 每世界原生CSR槽 |
| `ten_wrapadr` | 每世界全局行的动态点地址 |
| `ten_wrapnum` | 每世界全局行的动态点数 |
| `wrap_obj` | 每世界`2*nwrap`个整数 |
| `wrap_xpos` | 每世界`6*nwrap`个坐标 |

合并保留浮点原始位模式。

GPU依次执行三次合并调用。

第二段写空间浮点行与坐标。

每个线程独占一个世界。
布局检查限制全部偏移与容量。

`update()`自动完成全局合并。
肌腱更新入口重算两类结果。
它要求附着与质心结果就绪。
单独更新局部行会废弃全局结果。
状态写入会废弃全部派生结果。
回读检查新增缓冲的双端守卫。
回读拒绝非有限浮点结果。
失败不发布部分宿主快照。
计划身份继续拒绝跨模型复用。
