# 肌腱速度设备消费者

日期：2026-10-14。
范围：P4、U020、G02前置子集。
本轮不交付完整速度阶段。
肌腱被动力接线仍待实现。

## 实际路径

```text
src/physics/tendon_velocity.rs
src/physics/resident.rs
```

公开接口如下。

```rust
TendonVelocityPlan
TendonVelocityData
TendonVelocityView
TendonVelocitySnapshot
```

计划借用实际运动学计划。
源保留原生全局肌腱编号。
消费者直接读取源设备雅可比。
它不复制整个雅可比缓冲。
它不下载后上传物理雅可比。
宿主回读仅服务诊断与验证。

新数据独占广义速度(qvel)。
柔体边保留自己的旧速度。
两者没有自动同步契约。
调用方显式更新新数据速度。
新入口支持整批与单世界写入。
合法写入废弃消费者就绪状态。
非法输入不改状态。

本入口要求非零自由度。
它也要求至少一条全局肌腱。
合法CSR行可以为空。
旧局部肌腱入口不能冒充全局源。

## 来源与寿命

源必须绑定同一实际模型。
源还必须绑定同一行拓扑。
检查采用真实共享对象身份。
相同形状不能代替计划归属。
消费者数据绑定自己的计划。
源与消费者世界数必须相等。

源必须显式完成肌腱阶段。
该检查也约束等价计划。
新入口不隐式重算位置阶段。
旧位置入口仍由调用方组织前置。
合法位置写入废弃源就绪状态。
冷源或脏源不能产生新视图。

成功更新返回只读视图。
视图同时借用源与消费者数据。
借用期间不能合法改写二者。
数据不提供独立当前结果读口。
调用方不能绕过源检查读旧缓存。
快照独占历史值。
快照不认证未来状态。
