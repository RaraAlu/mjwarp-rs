路由分母不等于物理字段分母。
八条路由各代表一个头部。
头部可能包含多个整数槽。

检查器独立冻结路由集合。
它也冻结每条上游字段集合。

每条路由记录以下证据：

- 宿主写入表达式。
- 设备读取表达式。
- 存储标量类型。
- 上游字段与原始声明。
- 直接复制或派生类别。

整份源码哈希保护上下文。
局部锚点帮助人工追踪。
格式守卫不替代语义分析。

## 浮点参数

以下十条物理参数路由采用f32。
柔体边打包器只返回整数。
浮点占位不计入物理参数。

| 路由 | 写入方式 | 设备读取 |
| --- | --- | --- |
| Hessian原始边长 | 直接复制 | `p[e]` |
| Hessian刚度 | 直接复制 | `stiffness=p+ne` |
| 柔体顶点 | 直接复制 | `verts=params` |
| 柔体初始坐标 | 直接复制 | `coords=verts+3*nv` |
| 柔体节点 | 直接复制 | `nodes=coords+3*nv` |
| 肌腱范围 | 独立批量复制 | `range` |
| 肌腱边距 | 独立批量复制 | `margin` |
| 固定肌腱系数 | 直接复制 | `coefficients[i]` |
| 空间肌腱滑轮系数 | f32倒数预计算 | `scales[i]` |
| 几何尺寸 | 独立批量复制 | `scales`中的尺寸区 |

滑轮预计算不会复制原始除数。
侧向点编号也使用包裹参数。
它先执行f32舍入，再转i32。
这两条路径不能混为直接复制。
本轮没有证明全部舍入语义。
后续仍须核对上游预处理链。

范围与边距各保留独立周期。
几何尺寸也保留独立周期。
本轮未改变任何批量参数。

| 路由 | 形成方式 | 审查边界 |

## 固定肌腱内部量

本轮映射四组实际表达式。
本库与上游都使用f32标量。
它们没有采用相同累加调度。

| 本库表达式 | 上游对应量 | 边界 |
| --- | --- | --- |
| `float sum=0.0f` | 长度输出的累加量 | 本库使用局部标量 |
| `coefficients[i]*qpos[qadr[i]]` | `L=prm*qpos` | f32乘法 |
| `jac[jslot[i]]=coefficients[i]` | 力臂写入`prm` | f32存储 |
| `length[t]=sum` | 长度原子累加 | 调度与舍入位置仍可能不同 |

本库每世界串行遍历肌腱。
上游按包裹对象执行原子累加。
因此同型不证明逐位一致。
本轮没有修改计算公式。
本轮没有新增数值放行证据。
