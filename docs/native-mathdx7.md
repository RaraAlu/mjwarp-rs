# 七维MathDx原生编译能力

日期：2026-10-14。
本轮确认非Python编译依赖。
本轮没有执行物理内核。

## 实际分支与ABI

DLL导出不能证明功能启用。
`native/mathdx.cpp`仅提供禁用stub。
真实实现位于`native/warp.cu`。
它调用cuSolverDx描述符接口。
它返回LTO与通用fatbin。
本轮核对头文件与调用声明。
两者均采用18个C ABI参数。
整数采用32位，bool采用1字节。
本地指针采用64位。

工具只装载受检绝对DLL路径。
工具限制依赖库搜索范围。
它先查询版本与编译旗标。
它再调用一次公开编译接口。
它不调用`wp_init`。
它不导入Python。
它也不读取模型或矩阵。
独立进程退出后释放DLL。
该探针不链接Rust产品。

## 冻结参数

参数跟随既有上游builder。

| 参数 | 值 |
| --- | --- |
| Warp | 1.15.0 |
| M、N、K | 7、7、1 |
| SM | 89 |
| 线程数 | 32 |
| 函数 | POTRF，枚举2 |
| 数值类型 | REAL、F32，精度枚举5 |
| A与B布局 | rowmajor，枚举1 |
| 填充模式 | upper，枚举0 |
| side与diag | -1，未指定 |
| 包含目录 | 0与空指针 |

编译符号保持以下名称：

```text
potrf_7_7_1_89_32_1_1_5_x_x_0
```

接口精度声明不证明内部全映射。
编译成功也不证明数值一致。
本轮不冒称完整生成内核。
SDK内部算子与SASS仍待核对。

## 首轮实测

运行命令：

```powershell
scripts/probe-windows-mathdx.ps1 -Attempt 1
```

DLL大小与摘要均匹配。
查询确认CUDA启用值为1。
MathDx启用值也为1。
