## 实际修复

冻结上游仍采用原提交：

```text
71da24d956378a87a703b6e1442b13aec0c4ac29
```

本轮核对实际生成指令(PTX)。
分块分解使用平方根倒数。
它先执行`rsqrt.approx.f32`。
随后乘主元得到对角因子。
它不等价于直接调用`sqrtf`。

乘减指令允许融合。
显式舍入修饰符会阻止融合。
此规则见[NVIDIA指令文档](https://docs.nvidia.com/cuda/parallel-thread-execution/#floating-point-instructions-mul)。
本轮保留同样的指令约束。
本轮没有全局关闭融合。
本轮没有打开快速数学选项。

第二次诊断误加舍入屏障。
它仍留下26个因子差异。
本轮依据指令规则撤去屏障。
第三次诊断验证最终修复。
状态1因子全部逐位一致。
同矩阵的状态0至6也一致。
状态7末项仍相差一个间隔。
因此，不宣称全状态逐位等价。

当前路由边界保持明确：

| 树大小 | 辅助路径 |
| --- | --- |
| 1 | 质量倒数 |
| 2至6 | 标量分解(Cholesky) |
| 7至64 | 对齐分块指令语义 |
| 大于64 | 反向分解(LDL)辅助 |

本轮不实现分块协作调度。
小型分支树仍有路由差异。
多自由度紧凑优化仍待实现。
本轮不证明全部大小等价。
