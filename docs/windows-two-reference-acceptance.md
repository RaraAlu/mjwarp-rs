## 1. 判定顺序

第一参考标准为原生MuJoCo。
原生字段块通过后直接通过。
此时不读取第二参考。
仅原生超差后读取冻结MJWarp。
第二参考通过也可通过门禁。
两路都超差才判数值失败。
缺少参考或容差则标记待验收。
待验收仍阻止T4通过。

判定始终检查完整字段块。
程序不逐元素拼接通过。
非有限值与长度错误直接失败。
身份、状态或拓扑错误也失败。
缺少有效原生参考不触发回退。
缺少容差不等于零容差。
逐位相等也不能填补容差缺口。

实现见[判定辅助](../tests/support/two_reference.rs)。
边界见[宿主测试](../tests/two_reference_policy.rs)。
