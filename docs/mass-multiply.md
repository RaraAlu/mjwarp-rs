# 常驻质量矩阵乘法

日期：2026-10-14。
范围：独立GPU乘法辅助。
本轮实现矩阵乘法(mul_m)。
本轮不重跑旧桥接用途。

## 原计划与接口

P4明确要求质量矩阵乘法。
它另要求forward阶段中间量。
依据见[实施计划](implementation-plan.md#p4-空间数学与基础动力学)。
上游映射登记U073/G03。
查询契约保留skip与替代M。
依据见[阶段契约](physics-stage-contracts.md)。

新源码位于以下位置：

```text
src/physics/mass_matrix/multiply.rs
```

```rust
MassMultiplyPlan
MassMultiplyData
MassMultiplyOutput
MassMultiplyFormat::{Sparse, Dense}
```

计划接收已校验CSR拓扑。
格式选择稀疏或稠密M。
数据独立持有默认与替代M。
向量和结果也采用独立缓冲。
`update`消费默认矩阵。
`update_with`可选skip与替代M。
每世界拥有独立skip标记。
skip早退保留原结果位型。
初始结果采用有限正零。
未初始化替代M采用NaN。
未跳过世界拒绝坏替代M。

合法M与向量写入废弃结果。
非法输入和外来计划保留结果。
世界写入检查范围与完整长度。
读回快照独立拥有宿主结果。
查询不自动执行forward。
查询不推进物理时钟。
接口不提供CPU物理回退。

该入口采用独立M/vec上传。
它尚未借用CRB设备矩阵。
它不提供共享广播或空DOF。
它不提供完整U073/G03调度。
Tile分解不是乘法的前置。
本轮不接入SDK或新增依赖。

## 新用途与容差

本轮采用两组冻结独立样本。
普通样本包含86自由度。
拥挤样本包含390自由度。
390规模跨越256线程边界。
新测试只消费静态原矩阵。
它不执行原分解、求解或CRB。
它也不调用任何旧测试函数。

向量采用独立已知解或LU解。
冻结RHS提供独立M*z对照。
新测试另计算f64逐行点积。
诊断只读取f32舍入后的M与vec。
该诊断不观察候选中间量。
本轮不运行任何参考作者。

执行前冻结abs/rel为2e-5。
本轮没有放宽执行后门槛。
旧容差与旧全部覆盖保持。
该新门槛不自动继承旧solve。
上游support_test采用5e-4。
它源于5e-5乘十的MuJoCo对照。
本轮门槛比该门槛更严格。
它仍只是独立诊断门槛。
它不放行冻结MJWarp静态等价。

两态、三向量与两种格式全覆盖。
每组世界规模为1、2、257。
合计72批、1485120输出槽。
最大绝对误差1.34351456e-6。
全部数值满足预冻结门槛。

两种格式均验证以下行为：

- skip仅更新世界256。
- 未选世界保持结果位型。
- 替代M不修改默认M。
- 返回默认M恢复原结果。
- 世界写入保留未选输入位型。
- 非法长度、越界与归属均拒绝。
- 快照不依赖数据与计划寿命。

Dense另采用非对称跨树替代项。
独立行点积验证该替代项。
测试不把它强制镜像化。
私有测试验证NaN、Inf与双端守卫。
源、结果与status故障均拒绝。
恢复后结果保持原位型。
跳过世界NaN不破坏保留结果。
未初始化替代M拒绝后可以恢复。
