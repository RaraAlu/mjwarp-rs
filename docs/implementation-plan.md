## 实施原则

先冻结功能，再选择工具链。
先验证双平台，再迁移物理。
先复用原生组件，再补缺项。
先确认算法，再优化调度。
先实现安全复制，再验证零拷贝。
先建立误差容限，再宣称等价。

内部原型可以缩小场景。
正式首版不能缩小GPU范围。
每阶段都保留双平台检查。
两种系统必须分别验收。
WSL成功不等于Windows原生成功。

## P1 Rust到GPU工具链原型

### 候选顺序

先验证CubeCL的两条CUDA路线。
优先评估双平台部署与成熟度。
CUDA C++生成路线现在允许。
LLVM/PTX路线也保留候选。
缺失能力可接入原生CUDA内核。
原生Rust CUDA仍作为候选。
项目不自研通用GPU编译器。

| 候选 | 核心价值 | 原型必须确认 |
| --- | --- | --- |
| CubeCL CUDA C++ | Rust内核生成CUDA C++ | 双平台、NVRTC依赖、原子与图 |
| CubeCL LLVM/PTX | Rust内核、IR与多后端体系 | 双平台、LLVM依赖、原子与图 |
| 原生CUDA C++ | 移植内核或补足GPU能力 | Rust FFI、双平台、编译与部署 |
| NVIDIA cuda-rust | 原生Rust到PTX编译链 | 原生Windows与工具链部署 |
| Rust-CUDA | 另一条Rust CUDA路线 | 当前编译器成熟度与双平台 |
| Rust-GPU | Rust到SPIR-V方向 | 后续跨厂商或显示路线 |
| cudarc等驱动包装 | 驱动与设备资源访问 | 与所选编译链的上下文契约 |

SPIR-V方向不替代CUDA首版。
驱动包装也不等于物理内核。

候选来源：

- [Rust-CUDA](https://github.com/Rust-GPU/rust-cuda)。
- [Rust-GPU](https://github.com/Rust-GPU/rust-gpu)。
- [cudarc](https://github.com/chelsea0x3b/cudarc)。

### CubeCL原型边界

候选源码同时包含两条CUDA路线。
一条生成CUDA C++。
另一条通过LLVM生成PTX。
原型分别显式选择两条路线。
不能只依赖默认feature行为。

核对feature合并的实际结果。
核对NVRTC与LLVM运行依赖。
核对图捕获和外部缓冲接入。
核对版本与缓存的可复现性。
登记实际生成源码与编译路径。
原生依赖不违反项目语言边界。
任何候选仍不得依赖Python。

源码快照：

```text
repository: tracel-ai/cubecl
revision: 1f73b9f63de50a17398c1d5278e2a5f11612c7e1
```

依据：[CUDA编译选择](https://github.com/tracel-ai/cubecl/blob/1f73b9f63de50a17398c1d5278e2a5f11612c7e1/crates/cubecl-cuda/src/compiler.rs)、[CUDA依赖](https://github.com/tracel-ai/cubecl/blob/1f73b9f63de50a17398c1d5278e2a5f11612c7e1/crates/cubecl-cuda/Cargo.toml)。

nightly与LLVM版本需单独锁定。

### 原生CUDA接入边界

允许手写或移植CUDA C++内核。
Rust保留安全调度与资源接口。
FFI明确缓冲所有权与完成事件。
内核共用选定的设备上下文。
原生内核不能隐式执行CPU物理。
原生移植不能保留Python生成链。
构建可采用锁定的原生工具链。
P1分别验证两种系统的路径。

复用原生库不等于复用GPU算法。
MuJoCo不导出GPU内核。
GPU模块仍需移植或重新实现。

- 无Python环境的构建与运行。

### 建议误差起点

以下数值仅供P0讨论。
项目尚未验证这些门槛。

| 测试族 | 建议起点 | 注意事项 |
| --- | --- | --- |
| 基础f32数学 | `atol=1e-5, rtol=1e-4` | 按输入尺度调整 |
| 无接触单步 | 同上，按字段归一化 | 四元数比较旋转误差 |
| 接触与约束 | 残差、穿透、力与能量门槛 | 不只比较接触数组顺序 |
| 长轨迹 | 统计量与任务行为 | 不要求逐位轨迹一致 |
| 深度与分割 | 解析几何与ID检查 | 固定相机及无命中规则 |
| RGB | 固定参数的图像容限 | 不要求跨平台逐像素一致 |

使用以下逐值比较公式：

```text
abs(actual - reference) <= atol + rtol * abs(reference)
```

四元数需处理等价符号。
接触比较需处理匹配与排序。
约束测试需检查物理残差。
长轨迹偏差不能掩盖单步错误。
