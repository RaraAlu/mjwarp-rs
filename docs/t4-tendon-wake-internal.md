## 内部量与输出

本轮映射十八组内部量。
本轮映射五项整数输出。
来源与逐组关系见[清单](evidence/t4-g03-retest/tendon-wake-internal/map.json)。

| 对象 | 精度或编码 |
| --- | --- |
| 肌腱长度、范围、边距 | 单精度(f32) |
| 两侧限位距离 | f32减法与严格比较 |
| 树链接、唤醒初值、最小值 | 有符号整数(i32) |
| 循环变量、树标记、计数 | i32 |
| 开关与限位标记 | 布尔值转i32 |
| 设备加载与存储 | u32位传输，保留符号位 |
| 大跨度寻址 | u64或s64整数地址 |

范围与边距保留独立周期。
内核直接读取常驻肌腱长度。
低侧采用严格小于比较。
高侧采用大于等于或无序跳过。
两种指令保持源码分支含义。
本轮检查相邻浮点数边界。
本轮不执行唤醒物理循环。

源树活动标记贯穿唤醒扫描。
新唤醒树不立即级联。
内核在末尾刷新树活动标记。
轻量刷新重算活动树计数。
它清零身体与自由度计数。
禁用或零肌腱时保留原计数。

输出依次采用以下布局：

```text
tree_asleep  ntree个i32
tree_awake   ntree个i32
ntree_awake  1个i32
nbody_awake  1个i32
nv_awake     1个i32
```

每世界宽度为`2*ntree+3`。
状态与暂存缓冲均采用i32。
流程先复制，再唤醒，最后交换。
两次同步启动都成功才交换。
回读仍返回整数向量。
诊断检查临时转换为f64。
该转换只检查有限性。
它不反馈产品物理结果。
